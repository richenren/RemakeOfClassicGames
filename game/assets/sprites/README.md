## 战场背景与 HUD 头像

- `graveyard_background.svg`：原创幽冥义庄战场背景，包含深蓝灰石板地面、墓碑、枯树、木栅栏、朱砂符纸与暖色灯笼。背景只绘制场景，不含 HUD、角色或静态敌人；角色、投射物和技能特效仍由 Godot 实时绘制。
- `player_portrait.svg`：256×256 年轻道士近景头像，用于左上角玩家状态面板；采用更立体的面部明暗、锐利眉眼、红色发带与黑金道袍，和实际战斗中的全身道士保持统一风格。
- 技能选择参考图仅作为视觉规范，不能把整张截图当作背景图或静态 UI；三张升级卡和所有文字/点击区域都必须保持真实交互。

## 技能卡插画

`skill_art_atlas.svg` 为六格 768×128 透明矢量图集：火符、雷符、铜钱剑、桃木剑、水/冰阵、地脉阵。每个格子独立绘制符纸、火焰/闪电、武器细节或阵法纹路，供升级技能卡直接使用；技能卡不再叠加主角人物肖像。

## 元素修炼插画

`element_cultivation_atlas.svg` 是原创的 768×128 六格矢量图集，依次绘制金系剑意、木系生机、水系清泉、火系余烬、土系地脉、雷系引雷。使用深色底纹、元素辉光、细金线与符箓/法器形态，视觉语言与既有技能图集一致。修炼卡直接使用独立图集，不叠加人物肖像，也不依赖外部素材。

## 运行时效果

- SVG 使用透明背景，脚本绘制的地面阴影、血条、受击闪白和状态环仍独立保留。
- 道士、行尸、跳僵、铁甲尸与尸王直接从 `creatures_atlas.png` 裁切最新角色设计；道士根据朝向切换正面/侧面姿态，移动采用加减速、转向缓动、重心倾斜、呼吸/步态起伏和短促攻击挥击反馈。普通敌人使用各自不同的加速度、步态频率与近身前倾，跳僵有平滑弹跳，尸王保留冲锋/蓄力状态机与二阶段红色气场。
- 尸王生命降至 50% 时切换二阶段素材。
- 火符获得后，每隔约 5 秒自动在目标位置生成持续 3 秒的火焰区域，区域内周期性造成伤害并附加轻度灼烧。
- 雷符的连锁伤害会绘制连接两名敌人的分段闪电，直接命中也会显示落雷与冲击光环。

## 约束与后续

- 这些是为当前 2D 俯视角原型单独绘制的可运行素材，不依赖外部游戏 IP。
- 当前全身 SVG 绘制尺寸：主角 76×96、普通行尸 56×76、跳僵 56×64、铁甲尸 62×80、尸王 96×116 世界像素。此前曾将角色缩小到 56×70/42×56，导致高细节 SVG 在实际视口中细节丢失、与背景脱节；现已恢复较大的绘制比例，并增加多层柔和地面阴影、接触阴影和暖色地面反光。完整八方向逐帧动画、独立受击/死亡帧仍需后续制作与实机校准。
- SVG 源文件是可编辑的矢量素材。修改资源名时需同步更新 `player.gd`、`enemy.gd` 和 `tests/test_smoke.gd`。

## 2026-10-29：贴纸感回归的原因与修正
- 原因：上一轮曾将主角缩至 56×70、普通行尸缩至 42×56 世界像素；细节丰富的 SVG 被缩小后脸部、衣纹和材质高光丢失。透明素材叠在深色地面上，加上单层硬边阴影，也强化了贴纸感。
- 修正：恢复主角 76×96、普通行尸 56×76、跳僵 56×64、铁甲尸 62×80、尸王 96×116；增加多层柔和地面阴影、接触阴影和暖色反光，角色本体采用轻微暖色校色。
- 说明：当前角色依然是 2D SVG 素材，本次是比例和场景融合修复，不宣称已替换成厚涂/写实原画。若后续需要彻底改变轮廓风格，应单独重绘或替换完整角色资源并制作对应待机/行走帧。


## 主角逐帧动画（2026-10-29）

`player_frames/` 保存年轻镇邪道士的独立透明 SVG 动画帧：待机 4 帧、移动 4 帧、符箓攻击 4 帧、受击 3 帧、倒地 6 帧。帧资源由现有角色矢量原稿按腿部、手臂、头部、腰间飘带与武器的局部姿态变化生成，保持服饰细节与统一坐标，不再只在待机/行走两张整图之间切换。`player.gd` 根据生命、受击、攻击和移动状态驱动逐帧播放；倒地动画使用更宽的透明画布，避免旋转时裁切。后续仍需按原始概念设定继续精修高细节动作帧，并在 Windows 图形窗口目视验收。


## 主角原型基线（2026-10-29，已更新为背剑方案）

主角身份、服装与跨会话规则见 [主角原型与资产交接记录](../../../docs/14-主角原型与资产交接.md)。高清身份/服装参考在 ChatGPT Library：`/Projects/RemakeOfClassicGames/角色设定/主角原型v1.0_装备位置参考_高清.png`。

- 用户最后确认的方案是**剑斜背于背部**，剑柄位于角色自身右肩附近，太极图案固定在剑柄根部/护手处；此前“左腰佩剑”规则已被取代。
- 正面视图中角色自身右肩在画面左侧；背面视图中右肩在画面右侧。侧面视图的剑柄仍位于右肩后上方。
- 剑鞘必须为刚性连续长鞘，不能弯折、换边、悬空或横跨脊柱形成错误斜挎。待机/移动/符箓施法/受击时保持背剑；近战拔剑动作另行制作。
- `player_taoist.svg`、`player_taoist_walk.svg` 与 `player_frames/` 仍是旧中间实现素材，不是新原型的最终游戏资产；不覆盖、不冒充、不直接接入，先完成独立透明背景原型验收。
- 本次更新只统一设计规范，不改变运行时 Sprite 引用和战斗逻辑。
