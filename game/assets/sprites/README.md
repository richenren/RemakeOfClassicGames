游戏当前优先使用独立 SVG 角色素材，旧版 `creatures_atlas.png` 暂时保留作为回退/对照资源，不再由玩家和敌人脚本直接引用。

## 运行时效果

- SVG 使用透明背景，脚本绘制的地面阴影、血条、受击闪白和状态环仍独立保留。
- 道士与行尸根据步态相位切换两张姿态；跳僵使用弹跳高度，铁甲尸/尸王采用低频重步与较小姿态摆动。
- 尸王生命降至 50% 时切换二阶段素材。
- 火符获得后，每隔约 5 秒自动在目标位置生成持续 3 秒的火焰区域，区域内周期性造成伤害并附加轻度灼烧。
- 雷符的连锁伤害会绘制连接两名敌人的分段闪电，直接命中也会显示落雷与冲击光环。

## 约束与后续

- 这些是为当前 2D 俯视角原型单独绘制的可运行素材，不依赖外部游戏 IP。
- 角色尺寸在脚本中按游戏世界像素统一缩放；更完整的八方向走路、攻击、受击和死亡帧仍需后续制作与实机校准。
- SVG 源文件是可编辑的矢量素材。修改资源名时需同步更新 `player.gd`、`enemy.gd` 和 `tests/test_smoke.gd`。
