# 角色与敌人贴图图集

文件：`creatures_atlas.png`（384 × 256，透明背景）

此图集由此前确认的《镇邪录》原创美术设定表中“俯视角 2D 游戏内角色/敌人帧”裁切整理而来，去除深色设定板背景后供 Godot 原型直接绘制。它是第一轮可用贴图，不代表完整动画帧或最终美术交付。

## 图集区域

坐标均为图集像素，格式为 `x, y, width, height`。

| 名称 | 区域 | 用途 |
| --- | --- | --- |
| 道士待机 | `37, 29, 53, 70` | 玩家静止 |
| 道士移动 | `169, 29, 46, 70` | 玩家移动 |
| 行尸 | `300, 29, 40, 70` | 普通近战敌人 |
| 跳僵 | `43, 158, 42, 68` | 快速敌人 |

| 尸王 | `280, 146, 80, 91` | Boss |

## 实现约束

- 战斗数值、碰撞半径、敌人生成与攻击逻辑不因贴图替换而改变。
- 玩家暂时使用待机/移动两张静态帧切换；方向动画、受击动画和死亡动画尚未接入。
- 普通敌人显示贴图上方的细血条；尸王使用 HUD 顶部独立血条。
- 图集保留统一透明通道，后续可以用更高分辨率的逐帧 PNG 替换，但需同步更新区域常量和自动化测试。
