## 战场背景与 HUD 头像

- `graveyard_background.svg`：原创幽冥义庄战场背景，包含深蓝灰石板地面、墓碑、枯树、木栅栏、朱砂符纸与暖色灯笼。背景只绘制场景，不含 HUD、角色或静态敌人；角色、投射物和技能特效仍由 Godot 实时绘制。
- `player_taoist_portrait.tres`：从当前背剑原型图集提取的 64×64 HUD 头像，与战斗角色保持统一。旧 `player_portrait.svg` 保留作回滚参考。
- 技能选择参考图仅作为视觉规范，不能把整张截图当作背景图或静态 UI；三张升级卡和所有文字/点击区域都必须保持真实交互。

## 技能卡插画

`skill_art_atlas.svg` 为六格 768×128 透明矢量图集：火符、雷符、铜钱剑、桃木剑、水/冰阵、地脉阵。每个格子独立绘制符纸、火焰/闪电、武器细节或阵法纹路，供升级技能卡直接使用；技能卡不再叠加主角人物肖像。

## 元素修炼插画

`element_cultivation_atlas.svg` 是原创的 768×128 六格矢量图集，依次绘制金系剑意、木系生机、水系清泉、火系余烬、土系地脉、雷系引雷。使用深色底纹、元素辉光、细金线与符箓/法器形态，视觉语言与既有技能图集一致。修炼卡直接使用独立图集，不叠加人物肖像，也不依赖外部素材。

## 运行时效果

- 新怪物 WebP 概念图集为透明背景，脚本绘制的地面阴影、血条、受击闪白和状态环仍独立保留；旧 SVG 资源保留作回退。
- 主角待机仍使用背剑四向静态图；行走切换到四张独立透明 PNG，每张 1×8 帧，分别对应正面/左侧/背面/右侧。`player.gd` 按 facing 选择图集并循环 8 帧。行走时取消旧的正弦上下弹跳、挤压和倾斜，脚底阴影保持稳定；不水平镜像角色，以免剑柄/太极图换边。施法/受击仍使用对应朝向静态姿态，后续再制作独立动作帧。普通敌人使用各自不同的加速度、步态频率与近身前倾，跳僵有平滑弹跳，尸王保留冲锋/蓄力状态机与二阶段红色气场。
- 尸王生命降至 50% 时切换二阶段素材。
- 火符获得后，每隔约 5 秒自动在目标位置生成持续 3 秒的火焰区域，区域内周期性造成伤害并附加轻度灼烧。
- 雷符的连锁伤害会绘制连接两名敌人的分段闪电，直接命中也会显示落雷与冲击光环。
