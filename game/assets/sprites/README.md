## 战场背景与 HUD 头像

- `graveyard_background.svg`：原创幽冥义庄战场背景，包含深蓝灰石板地面、墓碑、枯树、木栅栏、朱砂符纸与暖色灯笼。背景只绘制场景，不含 HUD、角色或静态敌人；角色、投射物和技能特效仍由 Godot 实时绘制。
- `player_portrait.svg`：年轻道士近景头像，用于左上角玩家状态面板；与实际战斗中的全身道士保持同一配色和面部风格。
- 技能选择参考图仅作为视觉规范，不能把整张截图当作背景图或静态 UI；三张升级卡和所有文字/点击区域都必须保持真实交互。

## 技能卡插画

`skill_art_atlas.svg` 为六格 768×128 透明矢量图集：火符、雷符、铜钱剑、桃木剑、水/冰阵、地脉阵。每个格子独立绘制符纸、火焰/闪电、武器细节或阵法纹路，供升级技能卡直接使用；技能卡不再叠加主角人物肖像。

## 元素修炼插画

`element_cultivation_atlas.svg` 是原创的 768×128 六格矢量图集，依次绘制金系剑意、木系生机、水系清泉、火系余烬、土系地脉、雷系引雷。使用深色底纹、元素辉光、细金线与符箓/法器形态，视觉语言与既有技能图集一致。修炼卡直接使用独立图集，不叠加人物肖像，也不依赖外部素材。

## 运行时效果

- SVG 使用透明背景，脚本绘制的地面阴影、血条、受击闪白和状态环仍独立保留。
- 道士与行尸根据步态相位切换两张姿态；跳僵使用弹跳高度，铁甲尸/尸王采用低频重步与较小姿态摆动。
- 尸王生命降至 50% 时切换二阶段素材。
- 火符获得后，每隔约 5 秒自动在目标位置生成持续 3 秒的火焰区域，区域内周期性造成伤害并附加轻度灼烧。
- 雷符的连锁伤害会绘制连接两名敌人的分段闪电，直接命中也会显示落雷与冲击光环。

## 约束与后续

- 这些是为当前 2D 俯视角原型单独绘制的可运行素材，不依赖外部游戏 IP。
- 年轻道士实际绘制尺寸为 88×112 世界像素，普通敌人绘制尺寸同步放大；角色尺寸在脚本中按游戏世界像素统一缩放。更完整的八方向走路、攻击、受击和死亡帧仍需后续制作与实机校准。
- SVG 源文件是可编辑的矢量素材。修改资源名时需同步更新 `player.gd`、`enemy.gd` 和 `tests/test_smoke.gd`。


## 2026-10-28 视觉精修
- \`graveyard_background.svg\` 与 2400×1600 世界画布保持原生尺寸，并增加义庄灵堂建筑、门窗木构、门前香炉、低对比地面符纹、湿石反光、苔痕与散落符纸/枯叶。
- \`skill_card_art_atlas.svg\` 是独立的横向技能卡主视觉图集：六种攻击技能 + 金木水火土雷六种修炼，共 12 幅 320×208 原创矢量插画。HUD 小图标仍使用原有方形图集；技能卡不使用人物肖像替代技能插画。
- 小视口改用紧凑 HUD 和更宽的战斗视野；触控按钮绘制坐标与命中热区共用同一布局计算。
