# 《镇邪录》Godot 可玩原型

## 当前阶段状态（2026-10-30）

- 主角背剑四向静态视图已接入；行走使用四张独立方向 PNG，每个方向 8 帧（每张 384×64，单帧 48×64）。
- 待机/行走绘制尺寸统一为 52×72；普通行尸为 56×76。
- 用户已在 Windows 实机确认：人物大小合适，走路动画勉强够用。本阶段先接受并冻结，不继续调整人物大小或步态。
- [Godot 4.5.1 CI：301 项通过，0 项失败](https://github.com/richenren/RemakeOfClassicGames/actions/runs/40999763853)。
- 本次反馈只确认人物尺寸与基本行走可用，不代表待机、施法、受击、死亡、背剑细节、其他视口和整套场景 UI 均已完成视觉验收。


这是项目的第一阶段可运行原型，使用 Godot 4.x + GDScript。主角使用透明 WebP 四向背剑静态图与独立八帧行走 PNG；怪物使用新生成的透明 WebP 概念图集（行尸/跳僵/铁甲尸/尸王独立区域），原 SVG 保留回退。义庄背景采用 2400×1600 原生画布，并加入废弃灵堂、门窗木构、地面符纹、湿石反光与环境碎屑。升级三选一使用 12 幅横向技能/修炼专属插画、黑金边框与元素强调色；小视口采用紧凑 HUD 和自适应战斗镜头，保留现有战斗逻辑、技能选择交互与输入热区。

## 运行方式

1. 安装 Godot 4.x 稳定版。
2. 在 Godot 项目管理器中导入本目录下的 `project.godot`。
3. 打开项目并运行主场景。

## 2026-11-02：战斗 HUD 定稿重排（用户指定方案 C 精简版）

依据用户上传的 1303×609 截图确认：**角色+生命在左上，当前目标紧随其下，时间/灵气在顶栏中央，右上角为暂停，右侧窄竖排自动技能图标，底部中间人物经验进度，左下方向引导/虚拟摇杆，右下主动道术与治疗按钮**。

- **仅修改常驻战斗 HUD 和实际 UI 输入映射**：\`hud.gd\` 新增 \`_reference_hud_layout\`、\`_draw_reference_hud\`，屏幕纵横统一比例计算，在 1303×609、1280×720、1067×744、800×600、640×360 均验证边界与热区。
- 战斗中取消大块「基础符箓数值」「当前构筑」文字面板；装备技能改为与现有四技能槽一致的右侧细窄图标栏。首个技能未学习时显示当前基础攻击，避免空白错觉；其余槽位为空位。
- 战斗 HUD 只展示当前已有的主动道术和治疗，不把设计中的两个新金系主动技能假装为已实现。现有技能 \`SPACE\` 和新快捷键 \`Q\` 均可释放当前主动道术，\`E\` 保持治疗，\`ESC\` 保持暂停；桌面底部按钮可用鼠标点击，Android 保留虚拟摇杆与触屏动作，右上暂停也可点击。
- 三选一升级面板、每关三次刷新以及此前技能图集**不变**。
- 已验收火场 \`fire_field_prototype.png\` 和 16 帧动态火焰 \`fire_field_animation_sheet.png\`、所有六系战斗伤害/冷却/碰撞完全不变。
- 如需回滚显示层，只需恢复旧的 \`_draw_hud\` 调度；旧 HUD 绘制方法暂留供对比与回滚。
- 重要：CI headless 只能验证布局、触屏热区、脚本导入与战斗用例；Windows 实际界面视觉验收仍以用户截图为准。
