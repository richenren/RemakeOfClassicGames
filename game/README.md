# 《镇邪录》Godot 可玩原型

这是项目的第一阶段可运行原型，使用 Godot 4.x + GDScript。角色和怪物使用独立透明 SVG 素材；义庄背景采用 2400×1600 原生画布，并加入废弃灵堂、门窗木构、地面符纹、湿石反光与环境碎屑。升级三选一使用 12 幅横向技能/修炼专属插画、黑金边框与元素强调色；小视口采用紧凑 HUD 和自适应战斗镜头，保留现有战斗逻辑、技能选择交互与输入热区。

## 运行方式

1. 安装 Godot 4.x 稳定版。
2. 在 Godot 项目管理器中导入本目录下的 `project.godot`。
3. 打开项目并运行主场景。

## 当前实现
- 技能美术规范：见 [技能卡视觉规范与 AI 出图提示词](../docs/12-镇邪录技能卡视觉规范.md)，包含六种攻击技能与六系修炼卡的独立出图提示词、反向约束和缩略图验收标准。
- 六系实战效果设计：见 [六系技能实战表现设计 Spec](../docs/13-镇邪录六系技能实战表现设计.md)，定义火球爆炸、雷击连锁、水球溅射、地刺突起、铜钱剑贯穿/回旋、桃木剑护身/追邪以及对应升级分支与最终进化。
- 视觉精修（2026-10-28）：升级选择面板继续使用更宽的三卡布局、更大的技能主视觉、金色云纹边角与较柔和的战场遮罩；新增 320×208 横向插画图集，覆盖六种攻击技能和金木水火土雷六种修炼；火符以符箓与朱红火焰为主体，土系地脉阵以龟裂地面、崩起岩柱和石屑震波为主体，明确区分两者的轮廓与配色。背景 SVG 提升至与世界画布一致的原生分辨率，并补充义庄灵堂和地面环境细节；800×600、640×360 使用紧凑 HUD，关键文字最小字号 9px；镜头缩放按视口比例计算，640×360 的缩放系数为 0.5，触控按钮绘制和命中布局保持一致。


- 1280×720 横屏基准视口、2D 摄像机跟随与原创幽冥义庄 SVG 战场背景（石板地面、墓碑、枯树、栅栏、符纸、灯笼）。
- Windows 键盘移动（WASD 或方向键）。
- Android 触屏虚拟摇杆、镇尸诀按钮和治疗按钮。
- 基础符箓自动索敌攻击。
- 行尸、跳僵、铁甲尸三种占位敌人；敌人追踪、轻量分离、接触伤害与常驻血条。
- 玩家生命条、无伤害数字、受击无敌窗口。
- 角色和怪物直接使用 `assets/sprites/` 内独立透明 SVG，不再从 `creatures_atlas.png` 读取裁切区域（旧图集仅留作参考）。主角 56×70 世界像素；普通行尸 42×56、跳僵 42×48、铁甲尸 46×60、尸王 76×90。主角、行尸、铁甲尸和尸王根据移动/阶段切换独立姿态，跳僵使用独立剪影与跳跃动作。HUD 头像升级为 256×256 黑金近景道士肖像。
- 局内成长：六大元素各有攻击技能与专属修炼；技能 Lv3 二选一分支，首次突破 Lv4 锁定主修，主修可到 Lv5、兼修封顶 Lv3；主修修炼可到 Lv3、兼修修炼封顶 Lv1。六种主修技能都需配合对应法宝才能解锁最终进化。
- 元素反馈：火符灼烧、水阵湿润、火+水蒸汽、雷+水导电；六种元素修炼卡使用单独绘制的金、木、水、火、土、雷专属矢量图标，延续黑金边框、柔和元素辉光与符箓纹样；火符持续火焰区域、雷符连锁闪电、六系最终进化均有对应战斗行为。
- 战场改为更有层次的义庄荒地：破损石路、墓碑、枯树、地面裂纹与微弱灯火。
- 灵气球、升级三选一与六种原型强化。
- 治疗库存（每局 2 次，每次恢复最大生命的 30%）。
- 约第 8 分钟生成尸王；初版具备冲锋、环形震地、延迟危险区域、50% 转阶段/暴走与短暂恢复窗口。障碍物撞停、完整 Boss 战场规则仍待实现。
- 当前阶段目标面板：显示镇压尸潮与尸王倒计时；尸王出现后切换为击败尸王，胜利后标记目标完成。
- 主动道术冷却条与就绪徽记；镇尸诀施放时显示短暂范围符纹脉冲。
- 升级三选一按参考图重构：中央黑金云纹面板、火红/雷蓝/剑金专属插画卡、类别竖签、技能说明与效果行；悬停高亮、键盘 1/2/3 和鼠标点击共用同一套响应式卡片布局。
- HUD 通过视口布局计算器定位玩家头像/生命、计时、主动道术、目标与构筑。1067×600、800×600 使用紧凑布局，640×360 使用超紧凑布局；紧凑构筑栏改为单行技能/法器图标，避免标题、等级和标签互相重叠。触控按钮绘制与命中区域共用同一布局计算，战斗镜头按视口尺寸缩放，升级卡片点击热区仍与绘制位置使用同一计算结果。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 镇尸诀 | Space |
| 治疗 | E |
| 暂停/继续 | Esc |
| 升级选卡 | 点击卡片或按 1/2/3 |
| 结束后重新开始 | R |
