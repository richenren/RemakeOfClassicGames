# 《镇邪录》Godot 可玩原型

这是项目的第一阶段可运行原型，使用 Godot 4.x + GDScript。已接入道士、行尸、跳僵、铁甲尸和尸王贴图，并新增六种国风技能插画 SVG 图集。移动表现包含道士两姿态交替、普通敌人脚步摆动/尘土、跳僵腾跃和尸王重步；敌人完整逐帧走路图集仍待美术帧补齐。

## 运行方式

1. 安装 Godot 4.x 稳定版。
2. 在 Godot 项目管理器中导入本目录下的 `project.godot`。
3. 打开项目并运行主场景。

## 当前实现

- 1280×720 横屏基准视口、2D 摄像机跟随与简单义庄/荒坟占位地图。
- Windows 键盘移动（WASD 或方向键）。
- Android 触屏虚拟摇杆、镇尸诀按钮和治疗按钮。
- 基础符箓自动索敌攻击。
- 行尸、跳僵、铁甲尸三种占位敌人；敌人追踪、轻量分离、接触伤害与常驻血条。
- 玩家生命条、无伤害数字、受击无敌窗口。
- 原创角色贴图：道士待机/移动；原创敌人贴图：行尸、跳僵、铁甲尸、尸王，统一存放于 `assets/sprites/creatures_atlas.png`。
- 局内成长：六种自动攻击技能、六种被动法器、四项通用强化、技能 Lv3 双分支、寒魄法器/水阵→冰魄阵、天雷法印/雷符→五雷敕令。
- 元素反馈：火符灼烧、水阵湿润、火+水蒸汽、雷+水导电；升级卡使用六种国风 SVG 插画，通用强化保留程序绘制图标。
- 战场改为更有层次的义庄荒地：破损石路、墓碑、枯树、地面裂纹与微弱灯火。
- 灵气球、升级三选一与六种原型强化。
- 治疗库存（每局 2 次，每次恢复最大生命的 30%）。
- 约第 8 分钟生成尸王；初版具备冲锋、环形震地、延迟危险区域、50% 转阶段/暴走与短暂恢复窗口。障碍物撞停、完整 Boss 战场规则仍待实现。
- 当前阶段目标面板：显示镇压尸潮与尸王倒计时；尸王出现后切换为击败尸王，胜利后标记目标完成。
- 主动道术冷却条与就绪徽记；镇尸诀施放时显示短暂范围符纹脉冲。
- 升级三选一卡片采用国风插画、金边符箓样式、悬停反馈与同步点击热区；选卡权重偏向已有技能升级，减少新体系连续挤占候选。

## 测试

- 测试范围与当前状态见 [`TESTING.md`](TESTING.md)。
- 自动化测试脚本：`tests/test_smoke.gd`。
- CI 工作流：`../.github/workflows/godot-prototype-tests.yml`。
- 本地运行逻辑测试：`godot --headless --path game --script res://tests/test_smoke.gd`。
- 导入/解析检查：`godot --headless --editor --path game --quit`。
- 主场景启动检查：`godot --headless --path game --quit-after 5`。

## 已知问题

- 结算界面已加入近乎不透明的居中结果面板，避免玩家/怪物与结算文字重叠；已增加布局自动化断言，仍需在 Windows 独立窗口复测实际观感，见 [`TESTING.md`](TESTING.md)。
- Godot 编辑器启动时可能改写 `project.godot` 并生成 `.uid` 文件；打开编辑器后应检查 Git 差异，不要覆盖其他本地修改。
- 编辑器内嵌视口较小时 HUD 左侧文字可能被裁切；独立游戏窗口正常。
- Windows 编辑器曾出现 WASAPI 输出设备日志，独立游戏窗口未复现，暂不作为游戏脚本问题处理。

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD / 方向键 |

| 暂停/继续 | Esc |
