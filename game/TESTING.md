### Windows 试玩发现的问题

1. **失败结算 UI 重叠（低优先级，已实施修复，待验证）**：`game/scripts/hud.gd` 的结算画面现在在背景遮罩上绘制近乎不透明的居中结果面板和边框，遮住角色/怪物在文字区域的干扰。已增加标题、统计文字、重新开始提示三个区域的面板覆盖测试；仍需在 Windows 独立窗口确认实际观感。
2. **编辑器可能改写 `game/project.godot` 并生成 `.uid` 文件（中优先级，工作区已恢复干净）**：本轮打开编辑器后已还原 `project.godot` 并清理生成文件。下次编辑器启动仍可能重新生成；修改前应检查 Git 差异，不要直接丢弃其他本地改动。当前占位美术不依赖纹理过滤设置，但该设置变化仍应作为待调查项记录。
3. **编辑器内嵌游戏视口 HUD 左侧文字被裁切（低优先级）**：小尺寸内嵌视口无法完整显示 1280×720 HUD；独立调试窗口中显示正常。建议使用独立窗口或放大编辑器进行验收。
4. **Windows WASAPI 音频设备日志（低优先级，暂不改游戏代码）**：错误来自引擎音频驱动，独立游戏窗口未复现，项目当前无音频资源。若后续加入音效，再检查 Windows 默认输出设备及占用情况。
