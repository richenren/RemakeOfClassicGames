# 《镇邪录》原型测试记录

## 本轮测试范围

- 工程导入与 GDScript 解析。
- 主场景启动。
- 玩家移动、步态相位、生命扣除、受击无敌窗口、接触伤害与治疗上限。
- 普通敌人追踪、交替步态反馈与脚步尘土触发。
- 行尸/跳僵/铁甲尸/Boss 的基础属性、追踪行为与 Boss 减速抗性。
- 普通敌人死亡后的击杀计数、灵气球掉落、拾取与经验增加。
- 自动符箓索敌、投射物命中伤害、镇尸诀伤害与冷却。
- 治疗次数消耗、经验升级三选一、升级效果。
- 当前阶段目标 HUD、尸王登场后的目标切换、胜利后目标完成状态。
- 升级卡片类别、六种独立技能插画 SVG 导入与图集区域映射、卡片居中标题/多行说明布局；镇尸诀施放视觉反馈触发。
- 六种自动攻击技能、六种被动法器、四项通用强化的候选池；首个升级保证攻击技能、后续按权重偏向已有构筑、通用强化每次最多一张。
- 技能 Lv3 双分支选择、冰魄阵进化条件、火符实际投射物、定时持续火焰区域、雷符连接闪电特效与火/水/雷状态交互。
- 修长道士、清朝僵尸、跳僵、铁甲尸/尸王独立 SVG 资源可加载、画布尺寸有效；道士与清朝僵尸有独立行走帧，尸王支持二阶段贴图。
- Esc 暂停/继续、分阶段尸潮上限、不同敌人经验收益、约 8 分钟尸王出场、尸王目标优先级、半血暴走/震地攻击事件及胜利结算。

### Windows 试玩发现的问题

1. **失败结算 UI 重叠（低优先级，已实施修复，待验证）**：`game/scripts/hud.gd` 的结算画面现在在背景遮罩上绘制近乎不透明的居中结果面板和边框，遮住角色/怪物在文字区域的干扰。已增加标题、统计文字、重新开始提示三个区域的面板覆盖测试；仍需在 Windows 独立窗口确认实际观感。
2. **编辑器可能改写 `game/project.godot` 并生成 `.uid` 文件（中优先级，工作区已恢复干净）**：本轮打开编辑器后已还原 `project.godot` 并清理生成文件。下次编辑器启动仍可能重新生成；修改前应检查 Git 差异，不要直接丢弃其他本地改动。当前占位美术不依赖纹理过滤设置，但该设置变化仍应作为待调查项记录。
3. **编辑器内嵌游戏视口 HUD 左侧文字被裁切（低优先级）**：小尺寸内嵌视口无法完整显示 1280×720 HUD；独立调试窗口中显示正常。建议使用独立窗口或放大编辑器进行验收。
4. **Windows WASAPI 音频设备日志（低优先级，暂不改游戏代码）**：错误来自引擎音频驱动，独立游戏窗口未复现，项目当前无音频资源。若后续加入音效，再检查 Windows 默认输出设备及占用情况。
