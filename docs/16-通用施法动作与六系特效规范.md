# 《镇邪录》通用符箓施法动作与六系特效规范

- 版本：V0.1 设计规范
- 日期：2026-10-30
- 状态：动作方案已确认方向；正式透明动作帧待制作与验收
- 适用角色：年轻镇邪道士
- 运行环境：Godot 4.5.1，2D 俯视角

## 1. 目标与边界

建立一套六系攻击技能共用的施法动作骨架，后续新增普通符箓、火球、雷符、金系剑气、水系法术、木系桃木/藤木法术、土系地刺法术时，优先复用同一套角色动作，只替换符纸/聚气/释放/弹体特效。

本规范不重新设计人物，不改主角身份、脸型、发型、服装、人物比例或装备。主角身份与装备以 docs/14-主角原型与资产交接.md 及 Library 高清原型图为准。

**背剑约束（不可违反）：**
- 剑全程斜背在背部；剑柄在角色自身右肩附近，太极图案固定在剑柄根部/护手处。
- 四方向均按原始方向绘制，不做水平镜像；正面、背面、左侧、右侧的剑柄位置遵循主角原型文档。
- 通用符箓施法不拔剑、不移动剑鞘、不让法器变成额外肢体。
- 飘带可有少量延迟摆动，但不得遮住剑柄、太极图和手部动作。

## 2. 通用动作骨架

六个语义阶段是动作设计与特效事件的统一接口。为保证衔接自然，正式逐帧资源建议每个方向 8 帧：6 个关键姿势 + 2 个过渡帧。

| 阶段 | 帧位建议 | 人物动作 | 动作重点 |
|---|---:|---|---|
| 1. 蓄势 | F0 | 重心略沉，身体保持稳定，空闲手开始抬起 | 不大幅下蹲，不改变人物高度和脚底锚点 |
| 2. 起手 | F1 | 持符手从腰/胸前自然抬起，另一手结剑指 | 符纸必须与手指/手掌有明确接触 |
| 3. 聚气 | F2-F3 | 符纸靠近胸前或肩前，剑指引导气流 | 能量聚集在符纸附近，不覆盖人物主体 |
| 4. 施法 | F4 | 持符手沿目标方向短促推出，身体轻微转动 | 手臂从肩肘自然延伸，不出现独立长袖/火把形状 |
| 5. 放出 | F5 | 符纸从手边释放，手势短暂停留 | 弹体从符纸前方生成；角色本体不拉伸、不被特效替代 |
| 6. 收势 | F6-F7 | 手腕回收，剑指放松，重心恢复 | 平滑回到待机/移动，不突然跳帧 |

### 动作节奏

- 初版目标总时长：0.50–0.60 秒；基础攻击间隔仍由现有战斗配置决定。
- 蓄势和起手短，聚气稍长，施法/释放清晰，收势干净。
- 移动过程中可以继续移动；施法朝向在一次动作期间锁定释放方向，但不得额外改变移动速度、碰撞或输入。
- 动作帧结束后回到当前移动/待机状态，不强制人物站桩。
- 施法触发由现有攻击事件驱动，不在动画脚本里重新实现攻击、索敌或伤害。

## 3. 四方向资产规范

- 方向顺序固定：正面（朝下）、左侧、背面（朝上）、右侧。
- 每方向 8 帧，合计 32 帧；四方向分别输出独立透明 PNG，避免依赖镜像。
- 推荐源帧画布：96×128 px；Godot 内继续按当前 52×72 世界像素绘制，人物脚底锚点与现有待机/行走资源一致。若最终清晰度与文件体积不理想，再统一调整源帧分辨率，不改变游戏内角色尺寸。
- 每张方向图集：8 列×1 行；单帧透明背景，无背景、地面、法阵、投射物、文字、边框或说明标签。
- 人物完整全身必须留在帧框内，脚底位置统一；发带/衣摆可小幅变化，但不得裁切。
- 角色脸型、发型、衣服纹样、袖口、腰间葫芦、背剑和剑柄锚点在所有帧中保持一致。
- 手持符箓属于角色动作资产的一部分；聚气环、火花、雷电、水流、石屑和最终弹体属于独立特效资产。

## 4. 六系特效：共用动作、独立视觉

当前接入范围：金、水、火、雷四系；木系、土系暂缓，待专项视觉设计完成后再接入。土系后续采用敌人脚下/指定地面位置生成地刺、岩刺和地脉冲击，不按普通飞行投射物实现。

| 元素 | 聚气表现 | 释放/投射物表现 | 主要色彩 |
|---|---|---|---|
| 金 | 符纸周围细金属光点/短环 | 铜钱、金刃、剑气或飞剑 | 暖金、铜色 |
| 木 | 细小叶片、藤纹沿符纸盘旋 | 木灵弹、藤蔓/桃木剑气 | 青绿、木褐 |
| 水 | 水滴与短弧水流环绕符纸 | 水球、水箭、水阵波纹 | 青蓝、冰白 |
| 火 | 朱红火星与短焰贴近符纸 | 火球、火舌、命中爆燃 | 橙红、暖金 |
| 土 | 低矮尘粒、符文从脚边/符纸下显现 | 岩刺、石块、地脉冲击 | 土黄、赭褐 |
| 雷 | 短促白色电弧在符纸边缘跳动 | 单束白色雷击、银白雷环、落点爆发 | 银白、淡冰蓝、纯白 |

规则：
- 元素色不能覆盖角色服装本色；特效强度与面积要受控，人物轮廓始终清楚。
- 聚气特效以手持符纸为中心，半径初版不超过角色绘制高度的约 0.35 倍；释放特效沿目标方向展开，不在人物身体中心凭空出现。
- 投射物独立于角色动画，沿现有技能轨迹移动；特效尺寸遵循当前已调小的投射物比例。
- 命中特效由投射物/范围技能负责，施法动画不承担伤害结算。
- 同一时刻多技能触发时，优先显示最重要的施法反馈，避免角色身上叠满多个大型光环。

## 5. 特殊技能边界

- 普通符箓、火球、雷符、金系剑气、水系法术、木系法术、土系地刺：复用通用六阶段动作。
- 铜钱剑/桃木剑：仍可复用施法动作；剑类弹体、剑影和回旋轨迹单独绘制，不从主角背部拔剑。
- 主动镇尸诀、终极道术、Boss 级招式：允许未来增加专属双手结印/大范围起势动作，但必须复用同一角色模型和装备锚点。
- 只有明确的近战拔剑技能才允许制作背剑解下、挥剑、归鞘的独立动作；不属于本规范范围。

## 6. Godot 接入建议

- 继续使用现有 Player 动画状态机和 cast 状态，不重写战斗逻辑。
- 新增四方向施法图集资源；按 facing 选取方向，按帧时间播放 8 帧。
- 施法动作只控制角色 Sprite 帧；聚气、释放、弹体、命中效果使用独立 Node2D/绘制层或现有 Projectile/技能特效系统。
- 技能配置只声明元素类型、特效 profile、弹体/范围效果和释放时机；不为每个元素复制一套 Player 动作。
- 当前程序绘制的手边小符纸仅是过渡占位效果；正式动作帧验收后再替换，不能同时叠加造成双符纸。
- 旧待机、四向行走、死亡、背剑图集保留；新资源采用新文件名，不覆盖旧资源。

## 7. 验收清单

### 视觉
- [ ] 六阶段动作一眼能读懂：蓄势 → 起手 → 聚气 → 施法 → 放出 → 收势。
- [ ] 符纸始终与手部接触；没有悬浮在头顶、胸口或身体正中。
- [ ] 手臂关节自然，不出现长袖火把、断臂、重复手臂或额外手掌。
- [ ] 四方向动作均正确；不水平镜像，不改变背剑方向。
- [ ] 剑柄、太极图、剑鞘在每帧保持同一身体锚点。
- [ ] 动作回到待机/移动时无明显跳帧；角色大小和脚底位置与现有 52×72 运行时尺寸一致。
- [ ] 六系特效能区分，但不会遮挡主角或比角色大得不合理。

### 工程
- [ ] 图集导入、四方向帧裁切、帧推进与动画结束回退通过 Godot 自动化测试。
- [ ] 施法期间仍可按现有规则移动/转向；不改变碰撞、索敌、伤害、冷却、射程或投射物速度。
- [ ] 基础符箓和六系技能均可触发通用动作；特效 profile 正确。
- [ ] Windows 实际窗口检查至少包含正面、左侧、背面、右侧施法与连续攻击。
- [ ] 用户确认动作后，才将新资源设为正式运行时素材。

## 8. 本轮概念参考的使用范围

本轮六阶段动作设计图只用于动作节奏、四方向适配和元素特效方向讨论。它包含背景、标注和多个示意角色，**不是透明角色 Sprite，不可整图导入 Godot，也不可直接裁切成正式动作帧**。正式资产必须按上述尺寸/锚点独立制作透明角色帧与独立特效素材。
