# 《镇邪录》开发交接与视觉适配记录

- 日期：2026-10-28
- 当前分支：`feat/godot-playable-prototype-v0.1`
- 目的：为新 ChatGPT 窗口/其他 AI 提供可直接继续工作的上下文，不需要用户重复说明已确认的设计。

## 1. 项目目标与已确认方向

- Godot 4.5.1、GDScript，2D 俯视角幸存者式 Roguelite。
- 首发目标平台：Windows 与 Android；本轮不做 Android 真机验收。
- 美术方向：国风手绘、中式志怪、幽冥义庄，深蓝灰石板、枯树/墓碑/栅栏、朱砂符纸与暖色灯笼；UI 为黑底鎏金、少量朱砂红/元素色。
- 升级构筑：金木水火土雷六系；角色达到 Lv6 后，技能 Lv3 突破 Lv4 才锁定唯一主修；主修攻击技能可到 Lv5、兼修最高 Lv3；主修修炼最高 Lv3、兼修修炼最高 Lv1；主修 Lv5 + 对应法宝才出现最终进化。主修确定前不出现新法器获取或元素修炼卡。
- 升级选择保持三张卡片，真实状态驱动，支持键盘 1/2/3、鼠标点击和触控；不能把概念图当作静态全屏背景。

## 2. 本轮代码改动

- 新增 `game/assets/sprites/graveyard_background.svg`：独立原创义庄战场背景，不含 HUD、角色或静态怪物；使用实时游戏实体覆盖其上。
- 新增 `game/assets/sprites/player_portrait.svg`：年轻道士头像，用于左上玩家状态面板。
- 当前运行时改为直接使用 `creatures_atlas.png` 的最新国风角色/怪物透明素材；旧 SVG 保留作回退，但玩家/敌人脚本不再引用。
- 主角缩至 54×100 世界像素；普通行尸 50×78、跳僵 50×76、铁甲尸 56×82、尸王 86×110。阴影独立固定在地面，角色本体使用加减速、转向缓动、步态起伏与短促攻击反馈。
- 更新 `game/scripts/main.gd`：使用独立义庄背景贴图替代旧的平面圆点与横向道路背景；战斗逻辑、角色、怪物和技能特效仍实时运行。
- 重构 `game/scripts/hud.gd`：玩家头像与状态、居中计时、右侧主动道术/构筑面板；升级三选一改为黑金云纹大面板、三张大插画卡、火红/雷蓝/剑金强调色、类别签、效果摘要、悬停反馈。
- 增加统一 `_hud_layout(view)` 与 `_level_up_layout(view)`，HUD 绘制和升级卡鼠标命中测试共享布局结果，避免卡片显示位置与点击位置不一致。
- 更新 `game/tests/test_smoke.gd`：新增角色图集与裁切边界、缩小后的角色尺寸、移动加减速、主修等级门槛、早期候选池和强制分支检查。
- 更新游戏说明、美术资源说明、界面规范和实施进度文档。

- CI 已覆盖：SVG 导入/解析、主场景启动、背景和头像资源、HUD 布局几何、升级卡点击区域共用布局，以及现有战斗/构筑逻辑。
- Headless 测试不验证实际美术观感。必须在 Windows 独立窗口检查：
  1. 1280×720：参考图的背景、主角比例、三张卡片层级与边框。
  2. 1067×744：非标准比例下 HUD 是否重叠或过度遮挡场景。
  3. 800×600 与 640×360：三张卡片是否完整、文字是否裁切、点击区域是否正确。
  4. 战斗时玩家和怪物是否被放大的贴图遮挡、碰撞半径是否仍合理。
- 当前背景为原创 SVG 2D 场景，不是 3D 建模；角色/怪物仍是 2D SVG 贴图与有限姿态切换，不是完整逐帧动画。
- Android 真机测试暂不在本轮范围；触屏安全区、横屏比例与性能后续再验收。

## 5. 运行与继续工作

在仓库目录：

```bash
git fetch origin
git checkout feat/godot-playable-prototype-v0.1
git pull --ff-only origin feat/godot-playable-prototype-v0.1
```

使用 Godot 4.5.1 打开 `game/project.godot`，按 F5 启动。逻辑测试命令：

```bash
godot --headless --path game --script res://tests/test_smoke.gd
```

新窗口继续时，请先读取本交接文档和 `game/TESTING.md`，查看本轮 CI 结果，再根据用户实机截图调整视觉。不要重复询问已确认的六系主修/法宝规则，也不要在未经确认时改成静态截图背景。
