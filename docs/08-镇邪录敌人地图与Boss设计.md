# 《镇邪录》敌人、地图与 Boss 设计 Spec

- 文档版本：V0.1 设计基线
- 状态：行为规则已确认；数值与节奏参数可配置
- 日期：2026-10-22

## 1. 地图结构

- 中型开放地图，连续战斗空间，摄像机跟随玩家。
- 少量固定障碍物用于路线选择与走位；不设计复杂迷宫或频繁切场景。
- 净化法坛位于固定位置，按阶段解锁。
- 尸王登场后形成一个较大的 Boss 战斗区域：足够玩家走位和拉扯，但不能继续利用整张地图无限风筝。
- **地图硬约束：第二法坛必须位于 Boss 战斗区域内或在该区域内可达**，以支持尸王登场后仍可继续净化。
- Boss 战区不持续缩圈；保留少量障碍物，但不能形成长期无伤卡位点。

## 2. 普通僵尸

普通敌人技能不使用独立的地面范围预警；不为普通怪额外绘制红圈/危险区域。Boss 的关键技能必须有明确范围预警。

| 敌人 | 战斗定位 | 行为 |
| --- | --- | --- |
| 行尸 | 数量压力 | 缓慢追踪玩家，成群接近；接触即造成伤害 |
| 跳僵 | 机动压力 | 通过跳跃/突进快速接近玩家；攻击/技能直接释放，不显示范围预警 |
| 铁甲尸 | 耐久压力 | 移动较慢、生命较高、抗击退；靠近后直接造成接触伤害 |

### 2.1 通用规则

- 普通敌人采用接触伤害，不要求每种怪都实现独立的攻击帧与命中判定。
- 玩家受击后的固定无敌窗口负责防止多敌人同帧连击造成瞬间清空血量。
- 敌人之间采用轻量级分离：可以高密度聚集，但不应长期完全重合；不使用完整刚体碰撞或复杂推挤。
- 分离行为不能强于追踪玩家的移动意图，避免尸潮自然散开。
- 普通怪血条常驻显示但不显示数值；样式细、短、低干扰。

## 3. 精英怪

- 从行尸、跳僵、铁甲尸生成精英变体，不额外制作独立精英基础模型。
- 精英出现时机由阶段配额、最小间隔、当前存活数量和战场压力控制；不能采用无约束简单随机。
- 同时存活上限初始建议 1–2 只，最终通过实机测试确定。
- 每只精英随机获得一个强化词条，首版词条池：
  - **迅捷**：提高移动速度。
  - **坚韧**：提高生命与控制抗性。
  - **狂暴**：提高接触伤害。
  - **霸体**：增强抗击退。
- 词条随机只发生在精英类型和生成时机已合法确定之后。
- 避免不合理叠加：例如原本已高度抗击退的铁甲尸，不应再次抽到几乎没有实际差异的霸体词条；具体兼容表由配置控制。
- 精英外观、血条和标识明显区别于普通怪；血条旁显示词条名称或图标。
- 精英是稀缺恢复道具、额外功德与高价值灵气的受控来源之一，不应成为稳定刷取的无限资源。

## 4. 普通敌人与掉落

- 普通敌人主要掉落灵气球；常规情况下不掉回血道具。
- 治疗来源主要由精英、法坛奖励与受控的 Boss 阶段来源承担。
- 灵气球规则见 [核心玩法与局内循环](06-镇邪录核心玩法与局内循环.md)。
- 治疗道具与治疗库存规则见 [界面、操作与反馈规范](09-镇邪录界面操作与反馈规范.md)。

## 5. 尸王 Boss

### 5.1 总体规则

- 约第 8 分钟登场。
- 两阶段 Boss，生命低于或达到 50% 时进入暴走阶段。
- 三种核心招式：冲锋、环形震地、延迟危险区域。
- 不加入吸收普通僵尸回血或强化的机制。
- Boss 战期间普通尸潮持续低强度刷新；前期不刷精英，只有战斗拖延到软时间压力后期才逐步允许精英介入。
- 所有关键技能有清晰预警与反击窗口。
- 每个关键技能结束后有短暂恢复/输出窗口；撞击大型障碍产生的冲锋硬直更明显。
- 技能采用半随机状态机，不是完全随机，也不是固定循环：有独立冷却、最近使用限制、合法条件，并根据玩家距离、阶段、场地状态加权选择。

### 5.2 冲锋

- 冲锋前在地面显示明确直线路径/危险带。
- 预警结束后沿路径高速冲锋。
- 小型障碍不应无限阻挡冲锋；大型固定障碍可以终止冲锋并令尸王短暂硬直。
- 同一障碍不能被无限稳定利用来制造长硬直，避免绕柱卡 Boss。
- 冲锋硬直应比普通技能恢复窗口更明显，但时长可配置。

### 5.3 环形震地

- 单次圆形范围爆发。
- 蓄力后对尸王周围明确圆形范围造成一次伤害并附带击退。
- 主要作用是驱赶贴身玩家；不做连续多段扩散波。

### 5.4 延迟危险区域

- 使用少量固定图案模板，例如十字、扇形、分区圆环。
- 一阶段只释放单一、容易识别的图案。
- 二阶段组合已有图案或缩短组合间隔，不重新引入一整套陌生机制。
- 危险区域爆发前必须有明确预警与可行走位窗口。
- 模板数量、范围、预警时间、组合间隔全部参数化。

### 5.5 阶段转换与暴走

- Boss 血量首次到达 50% 时触发短暂转阶段演出，例如尸气爆发、怒吼、场地震动。
- 转阶段期间玩家仍可移动；尸王短暂无敌，玩家攻击可以播放表现但不造成有效伤害，避免高爆发跳过二阶段。
- 二阶段主要提高技能频率与组合复杂度，只适度提升基础数值。
- Boss 血条样式在二阶段明显改变，但血量仍是一条连续血条，不设计第二条命。

### 5.6 Boss 战场与软时间压力

- 封锁区域较大，玩家仍有足够移动空间；不动态缩圈。
- 保留少量固定障碍物。
- Boss 战拖延时压力按以下顺序递进：
  1. 普通尸潮数量/生成压力上升；
  2. 受控精英怪开始介入；
  3. 小幅提高 Boss 技能频率。
- 不设固定倒计时判负。
- Boss 战期间仍可正常获得灵气、升级和强化；升级选卡期间战斗与计时完全暂停。
- 第二法坛若尚未完成，尸王战中仍可继续挑战；Boss 本身不会暂停或让招。

### 5.7 击杀与结算

- 尸王死亡后立即停止新敌人生成。
- 场上普通敌人和残余威胁快速清除或失效。
- 提供短暂收尾阶段，自动吸收附近灵气和合法掉落，再进入胜利结算。
- 尸王掉落“尸王精魄”，收尾阶段自动吸收。首次击败时作为关键记录/后续凝炁试炼资格条件之一；同一存档后续击杀不重复累计精魄，转为额外功德。
- Boss 被击败后不允许继续完成法坛或刷资源。
- Boss 失败与普通死亡采用同一套失败结算规则。

## 6. 生成与性能

- 敌人必须从视野外合法生成点出现，并遵守最小生成距离。
- 80–100 个同时存活普通敌人作为首轮目标；敌人数预算达到后降低生成速率。
- 使用对象池；性能压力优先通过降低生成速率/更新频率处理，而不是引入复杂物理系统。
- Android 实机测试决定最终敌人数上限、分离更新频率、特效数量和画质默认效果。
