# 《镇邪录》金系御剑流视觉实施记录

- 日期：2026-11-02
- 分支：`feat/godot-playable-prototype-v0.1`
- 美术决定：**B 鎏金剑锋**，以古铜实剑材质为基底；符纹仅施法和高等级微量出现。
- 元素定位：金系采用**御剑流**，普通攻击不再通过纸符视觉表现；基础技能仍为铜钱剑，保留原技能 ID `copper_coin_sword`。
- 关联参考：用户验收的火场截图；火场资源、16 帧/12FPS 和最终淡出完全冻结。

## 视觉分层

1. **御剑起手**：角色仍复用四向现有姿态与手部锚点，但金系起手不再绘制符纸；掌前出现短促鎏金剑芒、少量金属光点与微弱剑意弧光。角色背剑不拔出、不重复生成手臂。
2. **飞剑**：独立 SVG 透明素材 `game/assets/sprites/metal_coin_sword.svg`，包含清晰剑尖、五枚带方孔的古铜钱、鎏金锋边、剑格与剑柄。游戏绘制尺寸 24×44 世界像素，再使用现有技能弹体缩放系数。飞行朝向沿用已有弹体旋转。
3. **拖尾**：保留原有轨迹采样机制，金系单独渲染窄而渐隐的金色剑意条带和高光芯。贯穿仍直行，回旋仍沿原有贝塞尔返程，自然形成弧线残影，不增加新的飞行逻辑。
4. **命中**：`game/assets/sprites/metal_blade_slash.svg` 是透明弧形金属斩光，而非直线或圆形爆炸。随实际命中朝向旋转，搭配细小金属火星与极短白金闪点。
5. **贯穿**：同一飞剑依靠原判定继续飞行，后续命中仍触发锋刃切痕，不改变伤害递减或命中数量。
6. **回旋**：原有回程轨迹、速度、二次伤害不变；随路径形成细锐弧线，二次命中使用方向不同的轻型斩光。
7. **金锋剑阵**：主剑命中后仍按既有机制追加两段金系连锁伤害，视觉采用错峰交错的两道锋芒；微弱符纹仅在进化短时间内出现，不做满屏法阵。

## 核心边界

- **不改**：六系伤害、CD、索敌、距离、碰撞、穿透次数、回旋次数、额外伤害、构筑规则、升级分支和其他元素。
- **不改**：火场 `fire_field_prototype.png`、`fire_field_animation_sheet.png`、`_fire_sprite_rect`、`_fire_field_frame_index`、`_fire_field_frame_region`、`_draw_fire_zones`。
- **不改**：主角角色素材和背剑，四方向逐帧施法仍为后续独立美术工作。
- 金系武器实体视觉与角色背剑分别存在，不应画出角色拔背剑的动作。
- 静态 SVG 资产 + Godot 动态方向、渐隐和轨迹混合，避免把武器主体做成笨重的多阶段循环切换。

## Windows 验收清单

- [ ] 铜钱剑主体在真实游戏倍率下可辨认（方孔/锋边），没有大范围暗影或白边。
- [ ] 金系施法时无纸符、无第二只手、背剑未消失。
- [ ] 普通命中与金锋剑阵差异清晰，后者为错峰的两次金锋斩击，不是静态 X。
- [ ] 贯穿仍能连续穿过目标，回旋仍呈自然弧线且残影不会遮挡视野。
- [ ] 金、火、雷同时释放时无颜色串用；火场的亮焰/透明边沿与原批准效果一致。
- [ ] Windows 1280×720 和 800×600 实机截图/录屏，主角和敌人比例协调。
- [ ] 本轮 GitHub CI 通过后仍需目视验收，Headless 不能替代实际画面测试。
