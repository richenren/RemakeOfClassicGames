# 《镇邪录》技能构筑与成长系统 Spec

- 文档版本：V0.2 构筑规则实施版
- 状态：主修、元素修炼与六系法宝进化规则已实现；具体数值待试玩平衡
- 日期：2026-10-28

## 1. 构筑原则

- 不锁定职业，自由混合不同元素、技能与法器。
- 局内随机升级自然形成专精；技能构筑是策略核心。
- 两层体系：战斗技能决定主要攻击/控制行为，法器提供被动强化并可作为特定技能的进化条件。
- V0.1 先实现符箓、御剑、阵法；召唤流留待后续扩展。
- 四个自动攻击技能槽、一个主动道术、三个被动法器槽。
- 自动技能重复获得时升级，不额外占槽；主动道术和被动法器的升级规则分别定义如下。

## 2. 六大基础属性与状态效果

### 2.1 基础属性

| 属性 | 首版定位 |
| --- | --- |
| 金 | 铜钱剑等御剑攻击方向 |
| 木 | 桃木剑等驱邪/护身方向 |
| 水 | 水阵、湿润与控制 |
| 火 | 火符、灼烧 |
| 土 | 地脉阵、范围压制 |
| 雷 | 雷符、爆发与导电 |

冰不是第七个独立基础属性，而是水系的进化分支。

### 2.2 状态效果

- 火：灼烧。
- 水：湿润。
- 冰：减速/短暂冻结。
- 雷：伤害与导电。
- 状态持续时间可以刷新；对同一目标的重复触发应设置内部冷却/触发上限，避免无限触发。
- 精英与尸王对冻结、定身等强控制的持续时间缩短。
- 怪物只有软弱点、抗性和控制抗性，不设元素免疫。

### 2.3 首版元素反应

只实现两种精选反应：
1. **水 + 雷：导电**。
2. **火 + 水：蒸汽**。

反应效果、触发冷却和伤害参数后续平衡；不扩展成全元素组合矩阵。

## 3. 自动攻击技能

技能基础等级为 Lv1–Lv5，每个技能在 Lv3 进行一次二选一关键分支；但局内只允许一个主修元素的攻击技能升至 Lv5，其他攻击技能最高 Lv3。角色达到 Lv6 后，主修技能才可从 Lv3 突破 Lv4 并锁定主修；最终进化还需匹配法宝。角色 Lv6 前不出现立道突破、元素修炼或新法器获取卡。

| 技能 | 属性/体系 | Lv3 分支 A | Lv3 分支 B | V0.1 进化 |
| --- | --- | --- | --- | --- |
| 火符 | 火 / 符箓 | 烈焰：强化灼烧与持续伤害 | 散符：增加火符数量，偏群体清怪 | 焚天符阵 |
| 雷符 | 雷 / 符箓 | 连锁：增加传导目标 | 天罚：降低频率、强化单次爆发 | 五雷敕令 |
| 铜钱剑 | 金 / 御剑 | 贯穿：增加穿透与直线清怪 | 回旋：命中后返回，形成双段伤害 | 金锋剑阵 |
| 桃木剑 | 木 / 御剑 | 护身：强化环绕范围和击退 | 追邪：部分飞剑主动追击附近敌人 | 青木护身剑 |
| 水阵 | 水 / 阵法 | 寒流：强化减速，为冰系路线铺垫 | 潮涌：扩大湿润覆盖，强化元素联动 | 冰魄阵 |
| 地脉阵 | 土 / 阵法 | 镇岳：强化范围控制和击退 | 地刺：提高伤害频率与爆发 | 镇岳神印 |

### 3.1 升级规则

- 攻击技能首次获得时占用一个攻击技能槽；重复获得时提升已有技能等级。
- 技能满级后不再进入普通升级候选。
- 每个技能的 Lv1、Lv2、Lv4、Lv5 具体数值与效果按固定路线配置；除 Lv3 分支外，V0.1 不再增加技能内部分支。
- 分支决定当前局技能的玩法方向；技能进化是独立的后续质变。

### 3.2 V0.1 进化

| 基础技能 | 进化条件 | 进化结果与行为 |
| --- | --- | --- |
| 火符 Lv5 | 持有符箓秘卷 | **焚天符阵**：火符命中后留下持续燃烧的火场，强化范围压制 |
| 雷符 Lv5 | 持有天雷法印 | **五雷敕令**：强化雷击爆发与连锁清场；限制传导目标数和内部冷却 |
| 铜钱剑 Lv5 | 持有御剑诀 | **金锋剑阵**：命中后追加两段金色剑气，斩击附近邪祟 |
| 桃木剑 Lv5 | 持有护身玉 | **青木护身剑**：攻击时额外释放护身剑气，击退近身邪祟 |
| 水阵 Lv5 | 持有寒魄法器 | **冰魄阵**：强化范围减速与短暂冻结；精英和尸王控制时间更短 |
| 地脉阵 Lv5 | 持有阵法真解 | **镇岳神印**：召出更大范围的镇岳震波，强化压制与击退 |

- 进化替换原技能，不额外占攻击技能槽。
- 条件满足后开放进化机会；选中后才进化，不自动替换。进化机会的具体呈现方式（独立提示还是进入后续升级候选）尚未单独确认，实施时优先采用最简单、清晰且不打断规则的方案，并在试玩中验证。
- V0.1 六种攻击技能均配置对应的最终进化；但只有唯一主修元素的技能能够达到 Lv5 并触发最终进化。非主修技能最高 Lv3，不能因持有对应法宝绕过主修限制。

## 4. 被动法器

固定三个法器槽，首版六种法器；每件最高 Lv3。

| 法器 | 主要作用 | 兼容进化 |
| --- | --- | --- |
| 寒魄法器 | 强化水/冰控制 | 水阵 → 冰魄阵 |
| 天雷法印 | 强化雷系与导电 | 雷符 → 五雷敕令 |
| 符箓秘卷 | 强化火符 | 火符 → 焚天符阵 |
| 御剑诀 | 强化铜钱剑 | 铜钱剑 → 金锋剑阵 |
| 阵法真解 | 强化地脉阵 | 地脉阵 → 镇岳神印 |
| 护身玉 | 提升生存能力 | 桃木剑 → 青木护身剑 |

- 首次获得法器时占一个法器槽；重复获得同一法器时升级，不额外占槽。
- 法器达到 Lv3 后退出普通升级候选。
- 法器没有内部二选一分支或自身进化。
- 六种法宝分别对应六大元素的最终进化。立道前不出现新法器获取卡（已持有法器仍可升级），避免早期选择看起来像提前锁定流派；主修锁定后最多持有三个法器，并在下一次升级优先出现对应核心法宝。非主修法器仍可提供被动效果，但不会解锁当前主修的最终进化。
- 玩家在每个存档的战前配置中，可以启用或禁用已解锁法器；默认全部启用。

## 5. 主动道术

V0.1 两种主动道术，每局选择一个，独立于自动攻击槽和法器槽。

| 道术 | 定位 | 解锁 |
| --- | --- | --- |
| 镇尸诀 | 范围控制、紧急突围 | 新玩家默认拥有 |
| 护身咒 | 短时防御/护盾、提高容错 | 首次完成凝炁突破后解锁 |

- 每局开始必须重新选择已解锁的主动道术；新玩家可选范围只有镇尸诀。
- 每个主动道术最高 Lv3，采用固定成长路线，不做分支或进化。
- 升级卡低权重进入普通升级池；达到 Lv3 后退出候选。
- 主动道术使用单次冷却，不存次数；HUD 显示冷却环/倒计时。
- 释放时可继续移动，不打断自动攻击。
- 主动道术冷却可以受到少量冷却缩减影响，但总缩减上限需通过平衡确定。

### 5.1 护盾规则

护身咒等效果产生的护盾：
- 独立于生命值显示，护盾优先承伤。
- 不叠加；新护盾仅在其数值高于当前剩余护盾时替换当前值，否则保留当前护盾。
- 有固定持续时间；到期后剩余护盾直接清零。
- 破盾不额外播放特殊碎裂反馈，护盾条归零即可。
- 护盾数值、持续时间和护身咒成长数值均可配置。

## 6. 通用强化

V0.1 通用强化池只有四项：

| 强化 | 效果方向 | 等级上限 |
| --- | --- | --- |
| 身法 | 移动速度提高 | Lv3 |
| 纳气 | 灵气获取效率提高 | Lv3 |
| 广纳 | 灵气拾取范围提高 | Lv3 |
| 强身 | 最大生命提高 | Lv3 |

- 可重复获得，分别独立升级；达到 Lv3 后退出候选池。
- 进入普通升级三选一，但每次候选最多出现一张通用强化卡，整体权重较低。
- 核心技能/法器尚未成型时，候选生成优先保证有构筑类选项；不能让通用强化长期冲淡构筑。
- 不加入暴击、护甲、攻速等大规模通用属性系统。
- HUD 常驻紧凑显示四项强化等级；具体图标/布局由界面规范定义。

## 7. 境界、功德与局外解锁

### 7.1 境界体系

完整规划：**入道 → 凝炁 → 通玄 → 真人 → 天师**。

V0.1 只实现入道、凝炁，并完成一次完整试炼与突破。

### 7.2 凝炁突破

- 首次击败尸王并满足修行条件后，解锁凝炁试炼。
- 试炼为独立的 3–5 分钟关卡，复用现有地图和敌人资源。
- 试炼失败不扣功德、不降境界，可重复挑战。
- 突破凝炁后解锁护身咒，并开放高阶内容的资格。
- 不额外赠送大量永久属性；奖励以固定内容解锁为主。

### 7.3 功德与解锁

- 功德主要解锁法术、法器、主动道术；高阶内容可以同时要求境界与功德条件。
- 功德在本局结束时结算；失败也获得部分功德，已完成任务奖励保留。
- 首次击败尸王奖励独立记录；重复击杀转为额外功德，不重复发放首次奖励。
- 每个存档独立保存功德、境界、解锁内容、试炼进度和通关记录。
- 永久解锁与随机池启用状态分离。每个存档战前可启用/禁用已解锁法术和法器，默认全部启用。

## 8. 技能卡插画与展示规范（2026-10-28）

- 升级三选一的主视觉必须使用对应技能/元素插画；不得用道士或僵尸人物肖像替代技能插画。
- 新增资源 `game/assets/sprites/skill_card_art_atlas.svg`，每格为 320×208 横向画幅，共 12 格：六种攻击技能（火符、雷符、铜钱剑、桃木剑、水阵、地脉阵），以及金、木、水、火、土、雷六种修炼。
- 图集顺序：攻击技能 x 起点依次为 0、320、640、960、1280、1600；修炼图 x 起点依次为 1920、2240、2560、2880、3200、3520。原有方形图集继续供战斗 HUD 小图标使用，避免小图标与大幅插画互相牵制。
- 火/土主视觉必须一眼区分：火符（`fire_talisman`，x=0）以符箓、朱红火焰和上升火舌为主体；土系地脉阵（`earth_formation`，x=1600）以龟裂地面、崩起岩柱和石屑震波为主体，使用岩灰/土褐/暗金色，不得把土系误标为“火”，也不得复用火焰主体。
- 卡片保留黑金边框、云纹角饰和类别竖签；插画应占据卡片主要视觉区域，避免过多空白或用几何光效代替主体物件。
- 插画只负责表达技能/元素，不修改技能效果、候选权重、槽位、主修锁定和进化条件。最终进化仍要求唯一主修元素达到规定等级并持有对应法宝。
- Headless 测试覆盖资源导入、图集区域映射与小视口布局，但不能替代 Windows 实际画面验收。

技能插画的完整视觉语言、AI 出图提示词和验收流程见 [《镇邪录》技能卡视觉规范与 AI 出图提示词](12-镇邪录技能卡视觉规范.md)。

## 9. 当前版本边界

V0.1 不实现召唤流、全技能进化树、每级技能分支、复杂状态叠层或大型属性词条体系。内容扩展应通过新增数据配置与资源完成，不重写核心槽位、升级与存档模型。


## 10. 2026-10-29：升级节奏与候选池修正

- 主修突破设为角色等级 Lv6 的门槛；角色 Lv6 前，技能 Lv3 不进入普通技能精进池，避免角色等级很低时意外锁定主修。
- Lv6 且存在已完成 Lv3 分支的技能时，候选池保证出现一张明确的“立道突破”卡；只有选中它才会锁定主修并升至 Lv4。
- 主修确定前不出现新法器获取和元素修炼卡；锁定后优先保证主修核心法宝。法器卡会明确区分“主修法宝”与“辅助法器”，不再把所有法器都标成可解锁当前进化。
- Lv3 分支为真正的二选一：两张分支卡之外的第三张为不可选提示，不允许用法器或通用强化跳过分支。
- 进化在候选生成和实际应用两处都校验主修、技能 Lv5、已选分支、对应法器和未进化状态，避免异常卡片绕过条件。
