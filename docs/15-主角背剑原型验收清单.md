# 《镇邪录》主角背剑原型验收清单

- 日期：2026-10-29
- 分支：`feat/godot-playable-prototype-v0.1`
- 当前阶段：外观与背剑方案已确认；独立透明视图为待验收原型，不是运行时素材。

## 已确认的视觉基线

- 年轻、修长、英气的中式镇邪道士；长黑发高束、暗红发带与飘带。
- 黑、深棕、赭金多层道袍，精细金色刺绣与符纹，破损的米金色衣摆、护腕、腰带、铜色葫芦法器和布靴。
- 剑斜背于背部；剑柄在角色自身右肩附近；太极图案固定在剑柄根部/护手处。
- 该背剑方案取代此前的左腰佩剑约定。概念设定图不能直接作为整张游戏 Sprite。

## 独立视图验收标准

- [ ] 正面：剑柄与太极图从画面左侧的角色右肩附近露出；不在腰侧额外生成第二把剑。
- [ ] 面朝左的侧视图：剑柄位于右肩后上方，剑鞘连续贴背，不换到身体另一侧。
- [ ] 背面：剑柄与太极图位于画面右上肩附近；剑鞘向背部左下方延伸，刚性笔直。
- [ ] 面朝右的侧视图：仍然保持角色自身右肩锚点，不能因视角切换而换边。
- [ ] 太极图是剑柄/护手的一部分，不悬空、不移到背部中央、不混淆为腰间葫芦或衣服纹样。
- [ ] PNG 具备真实 Alpha 透明通道；没有棋盘格烘焙、概念图文字、分隔线、其他角色或边缘残留。
- [ ] 四视图的人物比例、面容、发型、服装主轮廓、材质和色彩保持一致。

## 资源与接入边界

- 当前独立视图用于原型审阅；未通过上述验收前，不制作动作帧、不接入运行时、不覆盖旧 Sprite。
- 通过验收后，先制作待机、移动、符箓施法帧；近战拔剑动画留到玩法明确需要时制作。
- 不改动自动索敌、伤害、冷却、碰撞半径、升级构筑、存档等战斗逻辑。
- 最终接入时运行 Godot 4.5.1 Headless 导入/自动化测试，并在 Windows 独立窗口检查角色比例、脚底接触、透明边缘、背剑锚点和小视口可读性。
- 文档提交与概念原型确认不能替代 Windows 实际画面验收。
