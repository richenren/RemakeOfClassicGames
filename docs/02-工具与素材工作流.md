# 免费优先的开发工具与素材工作流

## 1. 精简工具清单

| 环节 | 首选 | 是否免费 | 何时使用 |
| --- | --- | --- | --- |
| 游戏引擎和场景编辑 | Godot 4 | 免费/MIT | 必备 |
| 开发辅助 | 已有的 Cursor / Claude Code | 视订阅或 API 调用而定 | 可用任一工具，不是运行时依赖 |
| 版本管理 | Git + GitHub | 免费额度足够日常使用 | 必备 |
| 角色/地图/图像编辑 | Krita | 免费开源 | 替换临时美术时 |
| 像素画/逐帧动画 | LibreSprite | 免费开源 | 选择像素风时 |
| 图片裁切/批处理 | ImageMagick（可选） | 免费开源 | 批量素材标准化 |
| 音效编辑 | Audacity | 免费开源 | 音效阶段 |
| 2D 地图 | Godot TileMapLayer | 随引擎免费 | 关卡阶段 |
| 独立地图编辑器 | Tiled（可选） | 开源，购买/捐赠渠道因平台而异 | 编辑器需求明确时 |
| 骨骼/复杂动画 | Godot 内置动画；Spine 可选 | Godot 免费，Spine 付费 | 骨骼动画确实需要时 |
| 容器 | 群晖 Container Manager / Docker | 视 NAS 型号/DSM 支持 | NAS 同步阶段 |
| 后端/数据库 | Python + FastAPI + SQLite | 免费开源 | NAS 同步阶段 |
| API 测试 | curl / Bruno（可选） | 免费方案 | 服务端阶段 |

避免在启动阶段安装全部工具；只需 Godot、Git、任意现有 AI Coding 工具即可用占位形状开始。Godot 运行游戏不需要独立的 Python 或 Java 服务。

## 2. 美术素材流水线

1. **游戏内容确认之后**定义艺术风格：像素或手绘、俯视角度、素材比例、光源、调色板、角色面向。
2. 先用圆形、色块、简单图标验证操作和战斗手感。
3. 需要角色时，先制作设定板；再制作多方向视图和动作素材，避免 AI 每次生成不同外观。
4. 用 Krita 修图、去背景、分层；像素风时使用 LibreSprite 做逐帧动画；必要时采用 Godot AnimationPlayer/AnimatedSprite2D 或部件动画。
5. 地面与障碍物尽量做重复图块；技能特效优先考虑 Godot 粒子和 Shader，减少大量 AI 动作帧需求。
6. 统一导出 PNG、透明度、锚点与命名；在 Android 真机检查清晰度与显存消耗。
7. 在 `assets/SOURCES.md`（后续创建）记录外部素材的来源 URL、作者、许可和允许的用途。

### 建议命名

```text
character_<id>_idle_00.png
character_<id>_move_n_00.png
enemy_<id>_idle_00.png
weapon_<id>_icon.png
effect_<id>_00.png
tile_<biome>_<id>.png
```

命名格式仅作为建议；具体角色、装备及场景内容仍待确认。

## 3. 免费素材来源及授权

- Kenney（https://kenney.nl/assets）：许多素材包使用 CC0，但**每个资源包单独核对其授权**。
- OpenGameArt（https://opengameart.org/）：混合许可，下载时核对 CC0/CC BY/CC BY-SA 等具体条款，记录署名要求。
- Godot 官方素材和 Demo（https://github.com/godotengine/godot-demo-projects）：核对每个项目及包含素材的许可。
- Freesound（https://freesound.org/）：每个音效许可不同；优先 CC0，使用前检查。
- 自行录制音效 / AI 生成素材：保留生成过程与工具使用条款；AI 生成不能保证版权无争议或动画一致。

不使用未经授权的经典游戏 ROM、精灵、音乐、字体和商标作为可公开分发资源。个人家庭用途也不等于自动取得授权。

## 4. AI Coding 开发规约

- 每次只交付可运行的垂直切片：需求→方案→实现→Godot 打开/解析→运行测试→提交。
- 改动 `.tscn`、`.tres`、节点路径和 InputMap 时必须通过 Godot 实际加载验证，不接受“代码看上去正确”作为通过。
- 数据/逻辑用自动化测试；动画、碰撞手感、UI 和触摸操作必须手动试玩。
- AI 生成的代码、人像和图像素材必须人工审查，不能默认可直接用。
- 不上传 AI 服务密钥、证书、设备签名文件；通过环境变量或本地忽略配置提供。
- 版本锁定由首次编码任务执行，避免使用未经验证的插件版本。
