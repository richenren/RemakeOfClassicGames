# 《镇邪录》角色设计与差异化 Spec

- 文档版本：V0.1 设计基线
- 状态：角色方向已确认；具体数值与解锁成本可配置、待试玩平衡
- 日期：2026-10-22

## 1. 设计目标

首版用两个角色验证“同一套肉鸽构筑，不同角色带来不同战斗决策”的玩法：

1. 年轻镇邪道士：默认角色，均衡、易上手，适合探索不同构筑。
2. 老派镇尸道长：首个可解锁角色，偏控制与稳扎稳打，体现经典中式民俗驱邪气质。

角色差异应清晰但轻量。角色不是独立职业系统，也不应要求为每个人物重新制作整套技能、升级卡池或进化树。

## 2. 共享规则

- 两个角色共享移动、自动索敌、技能槽、升级、技能分支、进化、法器、主动道术、存档和结算系统。
- 共享 4 个自动攻击技能槽、1 个主动道术槽、3 个被动法器槽。
- 每个角色只有 1 个专属被动；首版不制作角色专属技能树或独立卡池。
- 首版角色差异优先由外观、专属被动与轻微的战斗倾向构成，不通过巨大基础数值差制造强弱角色。
- 为降低开发和调平成本，首版两个角色沿用相同的基础生命、移动速度和初始技能配置；如试玩证明确有必要，再考虑小幅差异。
- 专属被动的数值必须配置化；本 Spec 不将任何建议百分比视为已确认数值。

## 3. 角色一：年轻镇邪道士

### 定位

默认角色、均衡型、适合初次游玩与自由混合构筑。

### 外观规范

- 沿用《镇邪录》现有国风手绘、中式志怪、古朴克制的美术方向。
- 青灰/墨青为主色，符纸黄与朱砂红作点缀。
- 服装偏轻便实战派：短改道袍、收腿裤、布靴、符袋、桃木剑或铜钱法器。
- 轮廓简洁，头部、武器和腰间符袋在俯视角下易辨识。
- 避免华丽仙侠长袍、过多悬浮饰物和过密细节。

### 专属被动：符箓初成（暂定名）

- 设计方向：小幅强化符箓类自动攻击。
- 目的：给新玩家一个容易理解的输出优势，但不强制玩家走纯符箓流。
- 具体影响范围（例如火符、雷符以及后续符箓技能是否全部受益）由技能标签配置定义，不能通过硬编码技能名称散落判断。

## 4. 角色二：老派镇尸道长

### 定位

首个可解锁角色、控制型、稳扎稳打，擅长应对靠近的尸群并创造安全输出窗口。

### 外观规范

- 与年轻道士保持同一套画风、线条、材质、光影和角色比例，不得像来自另一款游戏。
- 只在年龄感、面部轮廓、胡须、道袍剪裁、配色与随身法器上做差异化。
- 采用中年、沉稳、干练的老派道长气质；深靛蓝、旧赭黄、暗褐为主，搭配符袋、铜铃、朱砂符纸和布鞋。
- 服装可以更厚实、层次更传统，但仍适合俯视角识别与 2D 动画。
- 作为对经典港式灵幻电影中民俗驱邪道长类型的原创致敬，不直接复制林正英本人肖像、特定影视角色的完整造型、剧照或可识别的专属设计；不宣传为林正英本人或官方授权角色。

### 专属被动：老道镇邪（暂定名）

- 设计方向：小幅强化对普通敌人的控制效果，例如减速或击退效果。
- 目的：鼓励玩家控制尸潮、调整站位，而不是单纯提高所有伤害。
- 精英与尸王仍保留已有的控制抗性规则；被动不能绕过 Boss 抗性或造成永久控制。
- 具体强化哪些控制效果及数值，须由状态/技能标签配置定义并经试玩验证。

## 5. 角色选择与解锁

- 新存档默认开放年轻镇邪道士。
- 老派镇尸道长作为第一个可解锁角色；建议通过累计功德或完成一项简单挑战解锁。
- 解锁条件、功德成本与是否需要挑战暂不锁定，避免在核心战斗尚未验证前引入额外平衡工作。
- 每局开始前选择角色；角色选择与每局主动道术选择是两个独立步骤。
- 角色解锁记录保存在当前存档槽内，各存档完全独立。
- 结算页的“再来一局”沿用当前角色；若角色选择流程另有统一战前入口，以该入口为准。

## 6. 首版范围与后续角色

### V0.1

只实现上述两个角色。先保证外观、选择、存档记录与专属被动完整工作，不扩展复杂职业系统。

### 后续版本候选

“雷法传人”可作为未来角色候选，方向为雷系与水雷导电反应的爆发构筑。它不是 V0.1 必做内容，也不应提前引入独立技能树。

## 7. Godot 2D 实现约束

- 使用同一角色控制器、移动、受击、死亡和技能系统，通过角色数据配置选择外观与被动。
- 被动效果优先使用数据标签/修饰器实现，避免在各个技能脚本中写大量角色 ID 分支。
- 角色选择 UI 只展示已解锁角色；锁定角色展示解锁提示，不允许通过界面绕过解锁校验。
- 首版优先复用基础动画状态：待机、移动、受击、死亡；攻击/施法动作按实际技能需求补充。
- 角色素材需按游戏内俯视角制作；概念立绘不能直接替代游戏 Sprite/动画帧。
- 验收至少覆盖：切换角色后被动正确生效、技能和法器槽位规则不变、存档槽之间解锁互不影响、锁定角色无法选用。

## 8. 原创性与素材记录

- 采用通用题材与原创组合，不直接描摹现成角色或影视截图。
- 保留角色设计迭代、提示词、生成时间和后续人工修改记录。
- AI 生成不等于自动获得完整商用权利；若计划公开发行，应检查所用工具条款、输入素材授权及最终设计与现有作品的实质性相似风险。
