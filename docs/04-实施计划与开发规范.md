### 阶段 4：本地多存档与恢复

- SaveManager、版本化 schema、原子写与历史回退。

- 本地约每 5 秒保存，关键事件立即保存。

- FastAPI + SQLite 服务端和容器部署清单。

- 版本校验、单写者保护、冲突提示、历史备份、离线重试。

验收：NAS 离线不影响游玩；多设备冲突不静默覆盖；可恢复历史版本。

## 单任务 AI Coding 流程

1. 任务必须包含背景、输入输出、边界、验收标准。
2. AI 先阅读 README 与相关 docs，提出最小可实现改动。
3. 实施改动，避免未经讨论引入新框架、服务和收费依赖。
4. 运行 Godot 头less 导入/解析与必要测试；手动通过实际画面验收关键交互。
5. 必须保留日志、失败用例与未解决问题，不允许虚报成功。
6. 每次小功能完成后提交清晰 Git commit。
7. 修改存档 schema/API 时同步更新设计文档、迁移测试。
8. 游戏逻辑和角色素材按目录管理；密钥、签名、.env、私人数据等严格忽略。

## 不做事项

- V0.1 不实现在线多人、召唤流、复杂装备掉落、全技能进化树或完整属性词条系统。
- 不因未来扩展可能而提前引入微服务、Redis、消息队列或复杂 ECS。
- 不使用未经授权的经典游戏原版素材。
