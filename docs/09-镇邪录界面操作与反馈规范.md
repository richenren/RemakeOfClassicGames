# 《镇邪录》界面、操作与反馈规范

- 文档版本：V0.2 参考图还原与响应式布局
- 状态：方案 C HUD 响应式布局与紧凑卡片已实现；570 项 Headless 自动化检查通过，Windows 独立窗口仍需目视验收
- 日期：2026-10-28

## 1. 平台与输入

- Windows：键盘移动。
- Android：触屏虚拟摇杆移动。
- Windows 键盘与 Android 触屏映射到统一的游戏输入动作；战斗逻辑不耦合具体输入设备。
- 自动攻击自动索敌，不需要瞄准操作。
- 核心战斗操作：移动、主动道术、治疗；V0.1 不提供闪避/冲刺按钮。
- 技术方案曾以横屏作为初步建议；本轮未单独锁定屏幕方向。原型阶段需优先验证横屏操作与 HUD，再最终确认方向、安全区、纵横比与布局。

## 2. 战斗 HUD

### 2.1 玩家状态

- 玩家角色头顶常驻简洁生命条。
- 主角与普通敌人优先使用统一风格的独立透明 SVG 角色素材，角色底部保留柔和接地阴影；移动时切换对应行走姿态，受击闪白、无敌闪烁不应遮蔽角色轮廓。
- HUD 主血量区域同时显示当前 HP / 最大 HP，例如 420 / 600。
- 低血量时使用血条变色、屏幕边缘轻微警示或心跳/提示音等方式提示；不提供低血量自动防御或免死。
- 护盾有独立的条/数值显示，优先承伤；详细规则见 [技能构筑与成长系统](07-镇邪录技能构筑与成长系统.md)。
- 受击后的固定无敌窗口内免疫伤害、击退与控制；具体时长待调优。
- 不显示伤害数字、治疗数字或暴击数字。

### 2.2 经验与构筑

HUD 常驻展示：
- 等级与灵气/经验进度。
- 当前阶段目标提示：尸王登场前显示“镇压尸潮”和登场倒计时；尸王登场后切换为“击败尸王”；胜负后显示对应结算状态。进度条仅表达登场进度或 Boss 已损失生命比例，不创建额外任务奖励。
- 主动道术按钮与明确冷却环/倒计时；冷却条随时间增长，准备就绪时高亮。
- 四个自动攻击技能图标与等级/状态，不显示实时冷却。
- 四项通用强化的紧凑图标与等级：身法、纳气、广纳、强身。
- 三个被动法器使用小图标或折叠展示，避免占据过多空间。
- 治疗按钮与剩余次数（0/2、1/2、2/2）。

### 2.3 敌人血量显示

- 所有怪物始终显示血量条，不显示具体 HP 数字。
- 普通怪血条细、短、低干扰，置于贴图头顶上方，适配 80–100 普通敌人同时出现的目标。
- 行尸、跳僵、铁甲尸应在体型、轮廓和配色上易于区分；尸王使用更大的独立贴图与低强度暗红氛围光。
- 精英血条更粗或有特殊边框/标识，并显示强化词条名称或图标。
- Boss 在屏幕顶部显示独立长血条、名称与血量百分比，不显示具体 HP 数值。
- Boss 进入二阶段后血条样式明显改变，但不分成两条命。
- 不显示伤害数字。技能命中、回血、破盾等信息通过血条变化、轻量特效和音效反馈。

### 2.4 当前原型的任务提示与升级卡片

- 当前目标提示是局内阶段引导，不等同于完整任务/法坛系统。
- 升级卡片应有明确的类别色、简洁图形标识、名称、效果描述和键盘/点击提示；类别至少区分攻击、身法、生存、灵气和道术强化。
- 卡片不能展示尚未实现的技能、法器或数值效果。
- HUD 使用暗色半透明底、低饱和金色细框和少量朱砂红印记；边框装饰不得挤占关键信息区域。

### 2.5 参考图还原与响应式布局（本轮实施基线）

- 美术方向沿用已确认的参考图：幽冥义庄、深蓝灰石板地面、枯树/墓碑/木栅栏、朱砂符纸与暖色灯笼；HUD 采用黑底、鎏金边框、少量朱砂红与青绿色状态提示。
- 战场背景使用独立原创 SVG 资源 `game/assets/sprites/graveyard_background.svg`，不包含静态角色、怪物、文字或 UI。玩家、敌人、投射物、技能特效和 HUD 必须保持实时绘制与可交互。
- 左上玩家面板使用独立道士头像、生命数值/血条、等级与击杀；左侧下方显示当前阶段目标。顶部中间显示生存时间与灵气进度；右侧纵向排列基础符箓/主动道术与当前构筑；底部居中显示操作提示。
- 升级界面使用中央大面板，背景战场保留可见但适当压暗；三张卡片保持等宽、等高、独立边框与充分间距。插画占卡片上半部，名称、类别、描述、效果摘要和选择提示分层排列。
- 攻击技能卡以元素颜色区分：火系朱砂红/橙，雷系靛蓝，剑系鎏金；元素修炼、法宝、通用强化使用各自矢量图标和类别标签。**技能卡不重复放人物肖像**。
- 响应式布局必须按实际视口尺寸计算面板和卡片；绘制位置与鼠标/触控点击热区复用同一个布局计算器，不能出现画面上的卡片与实际点击区域错位。
- 小屏优先缩放装饰与字号、压缩 HUD 次要信息，不应让三张升级卡越界或重叠；战斗期间右侧构筑信息尽量紧凑，减少遮挡角色与怪群。
- 参考截图仅为视觉目标，不作为整屏背景贴图。所有文字、状态、角色、怪物、卡片与按钮均须使用真实游戏状态驱动。

## 3. 主动道术操作

- 主动道术是独立按钮，显示单次冷却状态。
- 点击后立即触发技能；可以继续移动，自动攻击不中断。
- 施放反馈使用短暂的范围环/符纹脉冲，表达技能作用范围；不显示伤害数字，反馈结束后自动消失。
- 不支持储存多次施放次数。
- 冷却缩减允许少量影响主动道术，整体上限可配置。
- 镇尸诀与护身咒每个最高 Lv3；升级固定成长，不做分支/进化。

## 4. 治疗道具与治疗库存

### 4.1 拾取与库存

- 治疗道具主要来自精英、法坛稀有奖励或受控的 Boss 阶段来源；普通小怪常规情况下不掉落。
- 玩家靠近后自动拾取。
- 每次拾取增加 1 次治疗次数；库存上限 2 次。
- 库存已满时不能拾取，治疗道具留在地上。
- 治疗道具存在时间较长但不是永久存在；具体时长可配置。
- 即将消失的最后几秒通过轻微闪烁/透明度变化提示。
- 不在小地图或屏幕边缘标记治疗道具；只在实际视野内可见。
- 治疗次数只属于当前局，结算后清零。

### 4.2 使用

- HUD 有独立治疗按钮并显示剩余次数。
- 满血时按钮置灰/点击无效，不消耗次数。
- 点击后立即消耗 1 次，恢复最大生命值的 30%，不超过最大生命上限。
- 使用治疗不需要前摇、不锁定移动、不打断自动攻击。
- 治疗恢复比例固定，不被其他效果强化；最大生命提升会自然增加其绝对恢复量。
- 治疗时血条有短暂恢复动画/高亮，并可显示轻量治疗图标或提示；不显示治疗数字。

## 5. 护盾与受击反馈

- 护盾优先于生命值承伤，独立显示。
- 护盾不叠加；只有新护盾值高于当前剩余护盾时才替换。
- 护盾有固定持续时间；到期后剩余护盾直接清零。
- 护盾被打破时不增加专门碎裂特效或特殊音效，护盾条归零即可。
- 受击无敌期间不受伤害、击退或控制。
- 低血量警示不改变伤害、掉落或防御数值。

## 6. 暂停、设置与退出

暂停菜单包含：
- 继续游戏。
- 查看当前构筑/通用强化。
- 设置。
- 退出本局。

退出本局需要二次确认，明确说明本局将按失败结算；已完成法坛等合法收益保留，但不会获得尸王击杀、精魄或首通奖励。

### 6.1 局内设置

设置在暂停菜单中打开，修改后即时生效：
- 音量。
- 画面质量：低 / 中 / 高。
- 帧率上限：30 / 60 FPS。
- 不显示伤害数字，也不提供伤害数字开关。
- 不做震动反馈。
- 首次启动不检测设备性能，默认中画质；Windows 与 Android 默认目标 60 FPS。
- 画质预设统一控制粒子密度、光效/阴影强度等性能项。

## 7. 升级、法坛奖励与死亡流程

- 升级选卡期间完全暂停战斗和关卡计时；选定后恢复。
- 法坛成功后的稀有三选一同样暂停战斗与计时。
- 玩家死亡后停止正常战斗逻辑，播放短暂倒地/法力消散表现，再进入失败结算。
- 不设置死亡后的构筑中间页；本局主要构筑直接显示在结算页。

## 8. 结算页面

展示：
- 生存时间。
- 击杀数量。
- 最终等级。
- 两次法坛完成情况。
- 本局获得功德。
- 是否击败尸王。
- 本局主要构筑：四个攻击技能、三个法器、主动道术与通用强化。

按钮：
- **再来一局**：沿用当前存档与卡池启用配置，但重新选择主动道术。
- **返回主界面**：回到存档选择/配置入口。

## 9. 可读性与移动端约束

- 普通怪血条常驻是已确认需求，但必须保持细短、低对比干扰；精英与 Boss 信息层级更强。
- Boss 地面预警优先使用清晰形状和轮廓区分，不依赖伤害数字。
- HUD 避免覆盖虚拟摇杆、主动道术和治疗按钮；为异形屏留安全区。
- 当前实现已加入视口自适应布局与升级卡点击区域共享计算；1067×600、800×600 使用紧凑 HUD，640×360 使用超紧凑 HUD，构筑栏为单行技能/法器图标。必须在 1280×720、1067×600、800×600、640×360 等尺寸检查面板越界、卡片重叠、文字裁切和战斗视野。
- 最终尺寸、锚点、字号、触控热区与安全区必须通过 Windows 独立窗口及后续 Android 横屏真机验收，不以 Headless 测试代替视觉验收。
