# RemakeOfClassicGames

个人与家庭使用的跨平台 2D 游戏开发项目。

> 当前阶段：技术方案与开发工具选型已确定方向；**游戏题材、世界观、角色、关卡、数值、具体玩法尚待确认**。本仓库暂不进行经典游戏原作素材的复制或 1:1 复刻。

## 项目目标

- 第一款游戏类型：**2D 俯视角幸存者式 Roguelite（肉鸽）**，参考“吸血鬼幸存者”的核心循环，不复制受版权保护的素材、品牌或独特内容。
- 平台：**Windows + Android 优先**，保留 iOS 可移植能力。
- 游戏模式：单机、离线可玩；后期可增加本地双人和实体 USB 街机摇杆。
- 持久化：本地自动存档 + 家庭 NAS 的轻量云同步；支持关卡里程碑及可恢复的单局快照。
- 开发：AI 辅助迭代，**免费开源工具优先**，不为简单需求引入重型框架。
- 发布：当前仅个人与家庭使用，未来是否公开发布另行决定。

## 已选择的技术方向

| 模块 | 选择 |
| --- | --- |
| 2D 引擎 | Godot 4 稳定版 |
| 脚本语言 | GDScript |
| 渲染 | Godot Compatibility，真机测试后按需调整 |
| 输入 | InputMap + 键盘/手柄/Android 触屏虚拟摇杆适配 |
| 本地存档 | user:// 下的版本化快照，安全替换与回退 |
| 同步 | HTTPS REST API，离线优先，失败重试 |
| 家庭服务器 | 现有群晖 NAS，优先容器化部署 |
| 服务端 | Python FastAPI |
| 数据库 | SQLite，保留升级空间 |
| 开发/版本管理 | Godot 编辑器、Cursor 或 Claude Code、Git/GitHub |
| 美术 | Krita、LibreSprite（像素画可选）、授权素材/AI 生图 |
| 音频 | Audacity、适当许可的免费音效 |

选型为项目基线，不代表所有依赖或工具均必须安装；版本号要在启动编码时固定并验证兼容性。

## 约束

1. 未确认游戏内容前，不预设机甲、地图数量、关卡主题、成长机制等具体设计。
2. PC 和 Android 从首个可运行版本起持续验证；iOS 保留兼容，但导出需要 macOS/Xcode 等条件。
3. 客户端不能因 NAS 不在线而无法运行；网络服务不是单局战斗的权威实时状态源。
4. 开发按“小功能 → 启动验证 → 测试 → 提交”迭代。
5. 不上传 API 密钥、证书、签名文件、生产存档或未经许可的原版游戏素材。
